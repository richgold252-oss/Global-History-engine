# Contributing

Thanks for your interest in contributing to Global-History-engine! We welcome bug reports, feature requests, documentation improvements, and code contributions.

How to contribute
1. Fork the repository and create a feature branch from the default branch (e.g., `docs/add-example`).
2. Run the test suite locally and ensure all checks pass.
3. Open a pull request against the repository's default branch. Describe the change, rationale, and any migration steps.

Coding standards
- Follow the existing repository structure and naming conventions.
- Add tests for new behavior where appropriate.

Branching & PRs
- Keep PRs focused and small when possible.
- Include screenshots or recordings for UI changes.

Security & sensitive data
Never commit secrets, API keys, or credentials. Use environment variables and a secrets manager. See SECURITY.md for reporting security issues.
