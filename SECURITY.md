# Security

If you discover a security vulnerability, please report it responsibly.

For now, contact: security@your-domain.example (replace with project owner's contact).

Guidelines
- Do NOT post sensitive details in public issues.
- Provide a minimal repro or steps to reproduce, affected versions, and impact.
- We will acknowledge receipt within 3 business days and provide updates on remediation.

Secrets
- Do not commit secrets to this repository. Use environment variables or a secrets manager (e.g., AWS Secrets Manager, HashiCorp Vault).

Responsible disclosure
We appreciate responsible disclosure and will not pursue legal action against researchers who follow these guidelines.
